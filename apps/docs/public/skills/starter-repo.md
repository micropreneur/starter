# starter-repo

1. Read the root and nearest local `AGENTS.md`.
2. Identify the owning app or package before editing.
3. Keep auth provider code behind `AuthPort` and UI primitives on Base UI.
4. Run the smallest package-level feedback loop while iterating.
5. Finish with `pnpm turbo typecheck lint build test`.
6. Never add secrets, premium source, billing flows, or deployment side effects.
