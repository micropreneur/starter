# IndexLabel

Ontology: **Properties**

Tiny zero-padded index number (`01`, `02`, `03`) in the mono face with wide tracking. Pass `value={1}` or provide children directly.

```bash
pnpm dlx shadcn@latest add https://elements.micropreneur.dev/r/index-label.json
```

Install from the public Elements Free registry; the CLI writes source into your project.
