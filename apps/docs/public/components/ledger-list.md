# LedgerList

Ontology: **Interfaces**

Horizontal ledger-style row list. Each `LedgerRow` takes `index`, `name`, `meta`, a monospaced `figure`, a trailing `status` slot, and a `selected` state. Prefer this over tables for list surfaces.

```bash
pnpm dlx shadcn@latest add https://elements.micropreneur.dev/r/ledger-list.json
```

Install from the public Elements Free registry; the CLI writes source into your project.
