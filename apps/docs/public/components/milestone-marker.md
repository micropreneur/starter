# MilestoneMarker

Ontology: **Interfaces**

Vertical milestone list. `Milestones` wraps `MilestoneMarker` items, each with a circular marker, connecting rule, `title`, mono `meta`, and a `done` / `current` / `upcoming` status.

```bash
pnpm dlx shadcn@latest add https://elements.micropreneur.dev/r/milestone-marker.json
```

Install from the public Elements Free registry; the CLI writes source into your project.
