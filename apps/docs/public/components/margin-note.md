# MarginNote

Ontology: **Properties**

Small editorial annotation with a marker rule in `--mp-brand-highlight` (burnt orange in the Starter theme). Use sparingly for asides and guidance next to content.

The rule falls back to `--primary` when your theme does not define `--mp-brand-highlight`, so it works under any shadcn theme.

```bash
pnpm dlx shadcn@latest add https://elements.micropreneur.dev/r/margin-note.json
```

Install from the public Elements Free registry; the CLI writes source into your project.
