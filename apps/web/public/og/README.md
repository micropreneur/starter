# Social image source

`starter.svg` and `starter.png` are generated by
`apps/web/scripts/build-og-image.mjs`. Edit the copy or layout constants in that script, then run:

```bash
pnpm --filter web og:build
pnpm --filter web og:verify
```

The generator converts every visible glyph to an SVG path before rasterizing the 1200x630 PNG.
Neither output depends on fonts installed on the host. `og:verify` regenerates both assets in a
temporary directory and compares them byte-for-byte, so normal builds do not modify tracked files.
