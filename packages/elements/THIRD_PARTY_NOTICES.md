## TweakCN theme presets

Portions of the normalized color values in these free Elements themes are derived from [TweakCN](https://github.com/jnsahaj/tweakcn):

- Modern Minimal
- Amber Minimal
- Clean Slate
- Caffeine
- Ocean Breeze

TweakCN is licensed under the Apache License 2.0. The palettes were reduced to the Micropreneur semantic token contract, paired with local system typography recipes, and adjusted where necessary to satisfy the documented contrast checks. Starter does not load TweakCN code, scripts, fonts, services, or runtime assets.
